# Neon Space Defender

Ein rasanter, browserbasierter Space-Shooter mit Arcane/Anime-Einflüssen, sarkastischem Humor (à la Deponia) und motivierendem Waffen-Balancing.

## Features

- **Waffen-Arsenal:** Verschiedene Spielstile durch differenzierte Waffensysteme:
  - *Pulse:* Der solide Allrounder.
  - *Scatter:* Massive Zerstörungskraft auf kurze Distanz (Shotgun-Prinzip).
  - *Railgun:* Durchdringt Gegner, erfordert aber gutes Timing durch langsame Feuerrate.
- **Audio-System:** Unterstützt eigene `.wav`- und `.mp3`-Dateien für individuelle Soundtracks und Effekte.
- **Konfigurierbarkeit:** Separates Volume-Management für Musik und SFX sowie ein anpassbarer Screen-Shake-Effekt.

## Installation & Setup

1. Repository klonen:
   ```bash
   git clone https://github.com/MrBrackhaus/neon-space-defender.git
   ```
2. In das Verzeichnis wechseln und Abhängigkeiten installieren (falls Node.js/Vite verwendet wird):
   ```bash
   npm install
   ```
3. Entwicklungsserver starten:
   ```bash
   npm run dev
   ```

## Audio & Assets anpassen

Die Platzhalter im Ordner `public/assets/audio/` können problemlos durch eigene `.wav`- oder `.mp3`-Dateien (GEMA-frei für den öffentlichen Gebrauch) ersetzt werden.
